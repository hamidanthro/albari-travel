# Google Search Console — Daily Indexing Submission Plan

**Total URLs:** 194 · **GSC daily quota:** ~10–12 per property · **Plan:** 20 days

How to submit each URL:
1. Open https://search.google.com/search-console
2. Make sure property dropdown shows `albaritravelspk.com`
3. Paste each URL into the top URL Inspection bar → press Enter
4. Wait for inspection (~10–30 sec) → click **Request Indexing**
5. Wait for confirmation → next URL

Quota resets at midnight Pacific Time (which is ~12 noon PKT next day).

## Notes
- **You don't have to do this religiously.** The sitemap will get re-crawled every few days and Google will discover everything naturally over 2-4 weeks. Manual requests just prioritize specific URLs.
- **If you skip the long tail (Days 11+)**, the small districts will still get indexed via the sitemap — just a few weeks slower. Not a problem.
- **Track progress here** by checking off each `- [ ]` as you submit (mark `- [x]`).
- After Day 20, check the **Pages report** in GSC to see which URLs are actually indexed vs not. We may need to push some that didn't take.
